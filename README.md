# Build once, run on any agent — talk kit (FR · EN · ES · DE)

Ready-to-present material for the GitHub Universe 2026 talk **"Build once, run on any agent: a practical guide to agent skills"** (Andrea Griffiths, GitHub · Shishir Tewari, Procore), adapted for *Universe on the Road*.

Each language folder contains the same 16-slide deck with speaker notes and embedded demo videos:

| File | Content |
|---|---|
| `talk-build-once-run-on-any-agent-XX.pptx` | Deck with speaker notes; demo videos embedded (slides 6, 8, 9) |
| `talk-build-once-run-on-any-agent-XX-notes.pdf` | Slides + speaker notes, printable |
| `demo1-proof-agent-XX.mp4` | Demo 1 — Proof Agent (verifier skill) |
| `demo2-dataforge-XX.mp4` | Demo 2 — dataforge skills in Copilot CLI |
| `demo3-vscode-XX.mp4` | Demo 3 — same skills in Copilot in VS Code |

| Folder | Language |
|---|---|
| [`FR/`](FR) | Français |
| [`EN/`](EN) | English |
| [`ES/`](ES) | Español |
| [`DE/`](DE) | Deutsch |

**Timing:** slides 1–14 ≈ 25 min → leaves ~8 min for Q&A in a 35-min slot.

**Notes**
- Narration is synthetic (macOS voices). Demo 1 in EN is the original recording.
- The demo 3 screen recording shows the VS Code chat in French; narration and subtitles are translated.
